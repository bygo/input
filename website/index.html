I want to discuss about the project tomorrow.
I want to discuss the project tomorrow.
want to discuss → 表达强烈的意愿去进行某事（“想”不仅是愿望，更是推动后续动作的动机）。
tomorrow → 在此处作为时间状语限定讨论的具体时刻，将抽象的“讨论”锚定在“明天”。
discuss the project → “讨论项目”这一动宾结构是句子的核心事件，指明了互动的具体内容与对象。
